Open-Source .ahnu File Format Specification (v1)

Designed so encrypted media files can be created and opened identically across the VaultDrop Web App and future Android / iOS native apps.

Offset Size Field Description
0x00 4 B Magic ASCII AHNU (41 48 4E 55)
0x04 1 B Version 0x01
0x05 1 B Cipher Suite 0x01 (PBKDF2-SHA256 + AES-256-GCM)
0x06 4 B Iterations Uint32 BE (default 310000)
0x0A 16 B Salt Cryptographically random salt per file
0x1A 12 B IV / Nonce Cryptographically random 96-bit GCM IV
0x26 Var Encrypted Payload AES-256-GCM ciphertext + 16B tag wrapping [4B metaLen][JSON metadata][raw media bytes]
